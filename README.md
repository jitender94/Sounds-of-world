# 🌍 Sounds of the World (Sounds of Earth)

> An interactive 3D musical atlas. Explore the globe, discover regional musical traditions, listen to curated acoustic soundscapes, and delve into cultural heritage.

---

## ✨ Features

- **🌐 Interactive 3D Globe**: Built with Three.js featuring realistic atmospheric shaders, custom textures, and smooth orbital controls.
- **🗺️ Hierarchical World Atlas**: Clustered zoom system that reveals regional musical traditions as you navigate closer.
- **🎵 Authentic Regional Soundscapes**: Powered by Howler.js with smooth cross-fading, ambient loops, and synchronized playback.
- **🏛️ Cultural Heritage & Instruments**: Rich cultural context, historical lineages, and traditional instrument spotlights for each region.
- **✨ Fluid Micro-Interactions**: Smooth GSAP transitions, camera arcs, glassmorphism UI, and custom seals/glyphs.

---

## 🛠️ Tech Stack

- **3D Graphics**: [Three.js](https://threejs.org/)
- **Audio Engine**: [Howler.js](https://howlerjs.com/)
- **Animations**: [GSAP](https://greensock.com/gsap/)
- **Bundler & Dev Server**: [Vite](https://vitejs.dev/)
- **Typography**: Google Fonts (*Cormorant Garamond* & *Inter*)

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/jitender94/Sounds-of-world.git
   cd Sounds-of-world
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser at the local URL (typically `http://localhost:5173`).

### Production Build

To generate the optimized production bundle:
```bash
npm run build
```

Preview the production build locally:
```bash
npm run preview
```
